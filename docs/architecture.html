SD-agent · 自研 Agent 运行时底座（Harness）

架构总览 · 概念体系 v3 · 概念设计期（无实现代码）
核心命题（作者原话）：拔高能力上限是假的，只是尽可能地守住模型的底线，不要让它浪费时间、人力、物力、金钱、token。
能力上限 ≠ 运行行为：同一套权重在真实工程会话里会趋同退化（投降 / 过度服从 / 局部压全局 / 早期结论支配 / 伪进展），由底座运行时兜住。

四条公理 — 一切设计从这推出来

1 下限公理模型高智力低纪律，纪律靠工程不靠自觉。⚠ 边界：纪律是兜底不是枷锁——过度限制会降智，须找限制与自主的平衡点。
2 纪律外置公理规则的制定权与裁决权归配置和代码，不与模型博弈；单向注入干预是允许手段；接管裁决权、不接管推理权。
3 腐蚀公理自动化更新会腐蚀人工治理成果：人工标记不可覆盖、更新只许追加、变更可回滚、自愈限次熔断。
4 上下文不可靠公理上下文随时被压缩污染截断：唯一副本绝不放上下文里，关键状态外置，产物落盘可复查。

执行带 — 模型出智力，底座出 SOP；项目经理不替外包写代码

主执行体（常驻）
承载缓存前缀 / 目标锚 / 痕迹工作区，是连续性的载体
辅助执行体（星座）
按需派生 · 用完即弃 · 只回压缩摘要；不共享上下文者不得接需共享决策状态的活
大模型 Worker
推理 / 规划 / 工具使用自主权保留（不剥夺决策能力，只不担不可撤销后果的最终裁决）
归属判据：本轮必须看见的 → 底座上下文；噪声大只要结论的 → 辅助执行体；跨会话才用的 → 记忆按需读。

记忆系统 — 五层含共享层：两个独立组件 · 一样重要 · 相互耦合

私有记忆 L0–L3
L0 工作（目标锚） · L1 情景 · L2 语义（证据+置信度+作用域） · L3 反思
↕ 耦合
只经结构化痕迹
不传原始对话
共享记忆 L4
跨执行体全局共享；写入/读取结构化痕迹（来源/置信度/作用域/证据），自带衰减；完成判定 = 被下游读到并采纳
流水线：零散事实 → 整合（去重去矛盾）→ 观察 → 沉淀可复用知识（技能 / 知识页）；轻重分治：轻索引每轮注入、深记忆按需检索；记忆是税不是红利——写入有证据、召回有预算、过期必衰减。

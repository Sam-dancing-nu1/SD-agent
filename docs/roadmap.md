## 二、最小闭环 P0 定义

一句话：一条命令让 agent 在本仓库完成一个真实小任务，留下 diff、测试退出码、可回放轨迹三样证据，doctor 能对环境出体检报告。

### 四要素落点 × 五层工程地基映射

| 四要素 | P0 落点 | 对应地基层 | 该层 P0 最小代表物 |
|---|---|---|---|
| 模型接入 | 现成 OpenAI 兼容客户端直连模型端点 | 提示词工程 | 按环境组装的系统提示 + 工具目录 |
| 工具循环 | 单循环 + 最大轮熔断 | 循环工程 | 循环体 + 失败重试上限 |
| 最小工具集 | read / write / edit / bash 四件 | Harness 工程 | 工具白名单 + 危险命令确认雏形 |
| 轨迹落盘 | JSONL 只追加 | 上下文工程 | token 计数与预算上限 |
| （横切） | 事件契约 schema 首日定死 | 图工程 | P0 单执行体，留执行体接口位 |

### demo 运行时骨架

```
任务输入（一句话 + 本仓库）
  ↓

  ↓
┌── 工具调用循环（最大轮熔断）──────────┐
│  模型端点（现成 OpenAI 兼容客户端）    │
│      ↕                                │
│  工具执行：read / write / edit / bash  │
│      ↓                                │
│  拦截层雏形（白名单 ＋ 危险命令确认）  │
└──────────────┬─────────────────────────┘
               ↓
   轨迹落盘（JSONL 只追加，事件契约管格式）
               ↓
   验证器（diff ＋ 测试命令退出码）→ 完成判定
```

### doctor（P0 必备）

`sd-agent doctor` = 启动自检，输出 PASS/FAIL 清单：
1. 模型端点连通（一次最小调用）；
2. API 凭据在位（只报在/不在，绝不打印内容）；
3. 工具执行环境可用（文件读写、命令执行各探一次）；
4. 轨迹目录可写；
5. 依赖与版本信息（供排障留痕）。

定位：本阶段的调试器——任何"跑不通"先跑 doctor，把环境问题与逻辑问题分开。

### P0 验收（可复查证据）

- 一条命令跑通一个真实小任务（在本仓库内）；
- 证据三件：git diff、验证命令退出码、轨迹文件（含完整事件序列，可重放对账）；
- doctor 全绿；
- 口头完工无效，以上述文件与命令输出为准。

## 三、分期 P0–P5

- **P0 最小闭环**：CLI 二进制 = 模型接入 + 四工具 + 循环熔断 + JSONL 轨迹 + 验证器 + doctor。验收见上。
- **P1 骨架固化**：事件契约 schema 定死 + 契约测试；状态机最小版（调研→执行→验证三态先行）；轨迹迁 SQLite（随记忆模块）；回归测试架接现成 golden 任务集。
- **P2 上下文工程**：token 预算截断、目标锚固定区、记忆 L0 工作记忆。
- **P3 纪律拦截**：探针 L1（哈希 + 规则）、白名单 ∩ 状态准入交集从严、收敛三态检测（伪进展/振荡熔断）。
- **P4 观察面**：TUI 双终端雏形（工作面 + 事件流观察面），可交子代理/其他 AI 承担。
- **P5 记忆与外发**：记忆 L1/L2 检索（D10）、D7×D8 模型×运行时同批实测定档、桌面壳 + 分发签名（D3/D5①）。

每期完成定义统一：可复查证据 + 回归不回退。

## 四、测试方案（修订版）

1. **P0 验收测试**：doctor 全绿 + 1 个真实任务三样证据齐全。
2. **契约测试（P1 起）**：事件 schema fixture 过序列化断言；状态机流转矩阵表驱动，非法流转必须被拒。
3. **回归测试**：golden 任务集用现成的（不自造）。对账口径 = 工具调用序列 + 终态差异，不对逐字输出（模型非确定性）；每任务跑 N 次取通过率阈值。
4. **靶子对抗集**：P0 只记基线（先知道裸奔的退化长什么样），P3 起要求"兜住率"较基线提升；任务来源优先现成/半自动。
5. **成本账（横切）**：每任务 token / 轮数记入轨迹。"不浪费资源"是产品命题本身，成本是第一验收指标。
6. **外部基准**：不上（见拍板 8）。

## 六、风险与边界

- **demo 直接在本仓库跑**：改动全部受 git 管控可回滚；P0 任务选取只做安全小任务；bash 工具从第一天带白名单雏形，不做裸执行。
- **凭据安全**：API key 只走环境变量/本地配置（gitignore），任何文档、轨迹、日志不落密钥内容。
- **模型端点**：OpenAI 兼容 chat_completions 格式已实查（Hermes 侧既有配置），但 Rust 客户端直连的实测连通性是 P0 第一步，失败优先查网络代理环境差异。
- **事件契约首日定死（D4）**：P0 轨迹每行即一个事件，字段以 schema 定义，后续迁 SQLite/加 IPC 不重写历史。

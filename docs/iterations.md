1. **边界压缩与"切域不毁缓存"物理互斥**。四段结构把域快照放在基础前缀之后、历史之前（:126）；切域是"在其后追加新快照"（:127），退役快照必然夹在基础前缀与当前快照之间；在域边界把退役快照压成摘要（:129）即改写前缀中段。按前缀匹配规律，压缩点之后的当前域快照与历史段缓存全部失效——"保留当前域快照与缓存锚不动"的表述会让人以为压缩不付缓存代价。**建议**：显式写明压缩必然导致压缩点之后重算、只在低频域边界做且计入成本；或另给"不毁当前快照缓存"的物理方案。
2. **目标锚定区没有物理位置**。L0 工作记忆含目标锚定区（:98）、会话开始"初始化目标锚、一次性写入静态前缀"（:149）、硬约束 17 要求切换/压缩后强制重新注入（:243）、同页又要求运行时动态元数据与静态前缀物理隔离（:135）。四条叠加后，它落"冻结前缀"（不可更新→无法重注入）还是"增量附录"（每轮可变→谈不上钉死）未定。**建议**：初始目标进静态前缀 + 每轮在附录重注入一份受校验副本。
3. **记忆组件的"层"清单与实际子结构不一致**。L0–L4（:98–102）之外，同节还出现沉淀层（:113）、痕迹层（:281）、经验三格（:114）、轻索引/深记忆（:110）；"痕迹层"与 L4（:102）、"压缩摘要"（硬约束 18）与"结构化痕迹 / 高阶观察"（:189）是否同物未说。作者校准留下的正是这个口径问题。**建议**：补映射表——分层（存储容器，按时间尺度）× 升维（成熟度：事实→观察→知识页）是两根轴；并给痕迹 / 摘要 / 观察三个词定名。
4. **同一个工具白名单有两个来源**。域"真实切换工具白名单"（:77）与状态机"每状态准入工具白名单"（:87）同时存在，冲突与合成规则未定。**建议**：写明交集 + 拒绝优先，或把一方降为建议。
5. **靶子 11 没有机制承载**。提示注入与工具结果污染只在靶子清单出现（:261）；组件层有出站脱敏与钩子治理（:146）、参数级风险评估（:54），但没有"外部内容（工具结果、网页、文件）一律视为不可信数据、不得作为指令执行"的条款，而 §7 开篇要求每条机制对应具体靶子（:250）。**建议**：补一条硬约束。
6. **十二组件与五层工程地基的映射缺失**。§3 称"缺任一层即出现能力空洞"（:38），但没给十二件落哪一层的对照；记忆系统、工作区与隔离、自我进化的层级归属未定（架构图把记忆与横切机制单列在地基之上）。**建议**：补映射表，或明说两套是正交视角。

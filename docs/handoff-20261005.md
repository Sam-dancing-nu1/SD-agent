## 六、拍板决策全表（2026-10-05 全部已定，不得反向改动）

1. 形态：TUI/桌面独立安装；平台先 WIN+LINUX，macOS 后置；Windows 直接跑 exe。
2. 命令：统一 `sdagent`（TUI 主页），桌面快捷方式 / `sdagent --desktop`。
3. TUI：鼠标全量；主页大 Logo+空白对话框；双终端（默认 WT 弹新终端）；历史列表+Token 统计热力图；流式逐字丝滑。
4. 桌面：UI 重做后置 TUI 定稿（字体锐化/布局/参考 Codex）。
5. 系统提示词：中文；六段骨架 v3；静态 ≤1.3K token；人设 Codex 式类比定姿+Pi 式短篇幅；三态套路自研（调研/执行/验证）；防御=固定句式+分级触发（用户设置+JEV 式置信度决策，提示词零裁决权）；负面词表用 unbot 成品（不进提示词）；权威通道 `---[directive:<seq>:<source>]---`（seq 单调递增，source∈harness/gate/user，只走动态附录）。
6. 核心代码 ≤500 行/文件，超标即拆（组件解耦小文件小模块）。
7. 提交规范：Conventional Commits 前缀（feat/fix/docs/refactor/chore，Hermes 官方仓库 git log 实证）；提交说明只写 diff 的中文解释+轻微说明，**禁引用户指示/原话**（防逆向推导）；文档改动独立提交（docs: 前缀）；docs/ 留仓库不移出。
8. 双子代理纪律：派子代理写文稿时必须同时派复查子代理查漂移/幻觉；子代理自报一律独立复验。
9. 概念书人话导读不做；JEV 阈值/热力图维度/流式参数/安装链细节 = 主脑定+实测，不逐项请示。
